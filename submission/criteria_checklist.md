# Challenge criteria checklist

| Challenge need | FIREWATCH feature | Where to see it | Status |
|---|---|---|---|
| Harmonize MODIS and VIIRS hot spots | Source-aligned comparison and explicit calibration-status/limitations view; no conversion model is published | Harmonization status panel and **How it works** | PARTIAL — scientific harmonization not validated |
| Burning activity calendar | Daily year calendar with sensor-family and metric selectors | Main activity calendar | PASS for observed source summaries |
| Selected area of interest | Search/select country and click a map bubble | Country controls and spatial overview | PASS — country-level AOI only |
| Historical fire patterns | Per-year MODIS and VIIRS totals with completeness states | Historical records panel | PARTIAL — packaged years and source files are incomplete |
| Unusual conditions | No anomaly or percentile score without a valid baseline | Baseline analytics panel explains insufficiency | NOT IMPLEMENTED; limitation is explicit |
| Critical periods | No season start/peak/end or early-warning event without validated baseline | Baseline analytics panel explains insufficiency | NOT IMPLEMENTED; limitation is explicit |
| Use by emergency responders | Quick spatial and date-based inspection with source coverage and CSV export | Calendar, map, coverage and export controls | PARTIAL — exploratory, not an operational alert service |
| Use by scientists | Sensor/platform provenance, source metadata, method description and CSV export | Provenance section and documentation | PASS for traceable exploratory summaries |
| Use by land managers | Country/time exploration and downloadable records | Country selector, calendar and export | PARTIAL — country-level AOI, not management boundaries |
